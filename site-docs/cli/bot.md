# social-hook bot

Control the background bot daemon that continuously runs scheduler-tick and consolidation-tick to automate posting.

---

### `social-hook bot start`

Start the bot daemon.

**Options:**

| Flag | Type | Default | Description |
|------|------|---------|-------------|
| `--daemon`, `-d` | boolean | false | Run as background daemon |

---

### `social-hook bot status`

Check if the bot daemon is running.

---

### `social-hook bot stop`

Stop the bot daemon.
